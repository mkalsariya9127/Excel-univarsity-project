# 🎓 Excel University - Academic Portal & College Website

A modern and responsive university website portal featuring admission inquiry forms, academic program listings, campus life highlights, and faculty showcases built with Bootstrap 5.

## ✨ Key Features
- **Academic Course Directory:** Displays degrees, diplomas, and specialized programs with duration and fee details.
- **Online Admission Inquiry:** Clean, user-friendly inquiry form for prospective students.
- **Campus Life & Facilities:** Image gallery highlighting library, laboratories, and sports grounds.
- **Events & Notices:** Notice board section for campus news and upcoming seminars.
- **Mobile Responsive:** 100% responsive across all modern mobile and desktop screens.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic structure
- **Bootstrap 5:** Grid system, responsive navigation, and form elements
- **CSS3:** Custom academic theme styling and font integration
